# Lesson 003 — Boundary Modes and Coupon Matrices

## The design question comes before the dimensions

A boundary can be specified from two opposite directions.

### Dimension-driven

Use a dimension-driven boundary when the finished outside contour is primary:

```scad
boundary = dimension_boundary(
    name = "RECT_200X100",
    kind = "rectangle",
    size_x = 200,
    size_y = 100
);
```

The future path generator will determine how many cells fit inside that contour.

### Count-driven

Use a count-driven boundary when the experiment requires an exact number and size of openings:

```scad
boundary = count_boundary(
    name = "COUNT_3X3_SPAN5",
    cells_x = 3,
    cells_y = 3,
    clear_span_x = 5,
    clear_span_y = 5
);
```

Here `cells_x = 3` means three clear openings. It therefore requires four structural strands.

## Why the outside size is derived

For one axis:

```text
outside size = cells × clear span
             + (cells + 1) × strand width
             + 2 × edge margin
```

With three cells, 5 mm clear span, 0.8 mm strand width, and no edge margin:

```text
3 × 5 + 4 × 0.8 = 18.2 mm
```

The count and clear span remain the authoritative inputs. The outside dimension is an output.

## Clear span versus strand pitch

These terms are not interchangeable.

```text
clear span   = unsupported edge-to-edge opening
strand pitch = clear span + structural strand width
```

For the 5 mm coupon:

```text
clear span   = 5.0 mm
strand width = 0.8 mm
strand pitch = 5.8 mm
```

The bridge qualification applies to clear span, not centerline pitch.

## Pattern topology does not own coupon dimensions

`config/patterns.scad` now records where spacing comes from:

- `fixed_pitch` for dimension-driven finished parts;
- `boundary_clear_span` for count-driven coupons.

This prevents the same spacing value from being copied into both the boundary and pattern records.

## Schedules count completed structural strands

The constructor is now `strand_group()`, not `layer_group()`:

```scad
strand_group(
    orientation = 0,
    strand_count = 4,
    pattern_set_name = "OUTER2_SQUARE_INNER_HEX",
    clear_gap_after = 0
);
```

`strand_count = 4` means four reliable completed structural strands. Under the active process, each strand requires two deposited layers, so the group requires eight deposited layers.

Changing the nozzle or layer-height process does not change the schedule's structural meaning.

## Vertical clear gap is independent

`clear_gap_after` is empty Z distance after a complete group:

```scad
strand_group(0, 1, "SQUARE_COUPON", 2);
strand_group(90, 1, "SQUARE_COUPON", 0);
```

This describes:

1. one completed lower X strand;
2. 2 mm of clear vertical separation;
3. one completed upper Y strand.

For a 0.4 mm strand height, total stack height is:

```text
0.4 + 2.0 + 0.4 = 2.8 mm
```

## A coupon series is a Cartesian product

`config/coupons.scad` does not duplicate geometry. It references:

- four count-driven boundaries: 5, 6, 7, and 8 mm clear span;
- three stack schedules: 1, 2, and 3 mm clear vertical gap.

The complete test matrix contains:

```text
4 horizontal spans × 3 vertical gaps = 12 coupon cases
```

Five and six millimeters are within the current PLA+ qualified bridge limit. Seven and eight millimeters are intentionally exploratory.

## Why records are generated by list comprehension

The coupon boundaries are created with:

```scad
COUPON_BOUNDARIES = [
    for (clear_span = [5, 6, 7, 8])
        count_boundary(...)
];
```

This produces a list of record-like vectors without manually repeating nearly identical records. The generated records remain ordinary named records and can be retrieved with `named_record()`.

## Lesson result

Batch 003 has not drawn a grid. It has defined the vocabulary and authoritative inputs needed before a continuous path can be correct:

- perimeter size;
- clear-opening count;
- clear span;
- strand pitch;
- structural-strand count;
- deposited-layer count;
- vertical clear gap;
- coupon test matrix.
