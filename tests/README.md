# Tests

Batch 003 defines the first physical test matrix without generating geometry:

- 3 × 3 clear-opening count;
- 5, 6, 7, and 8 mm horizontal clear spans;
- 1, 2, and 3 mm vertical clear gaps;
- one completed X structural strand below;
- one completed Y structural strand above.

The Cartesian product contains twelve coupon cases.

Future automated tests will cover:

- one start and one end;
- no disconnected path sections;
- no closed independent loops;
- unsupported-span classification against the qualified bridge limit;
- correct derived strand width and height;
- boundary and schedule expansion;
- physical bridge sag, grout flow, and tolerance observations.
